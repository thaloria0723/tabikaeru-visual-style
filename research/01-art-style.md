## 1. 配色

### 1.1 核心结论

**【实测】主色是「低饱和暖灰系 + 一个黄绿家族」，不是「绿色」这么简单。**
四张截图的像素统计一致指向同一个结构：

| 主色 A｜砂／米 | `#D8D0A8` | H=50° S=0.22 V=0.85 | 庭院 17.8%，最高单色 | 地面、沙土、纸面基调 |
| 主色 A'｜亮米 | `#DFD1AE` | H=44° S=0.24 V=0.87 | — | 同上，亮部 |
| 主色 B｜冷灰 | `#B8BFC5` | H=207° S=0.07 V=0.77 | 室内 9.9% | 石屋／石墙。**实测 SD=0.00，绝对平涂** |

**性格判定（实测数据支撑）：**
- **饱和度：低到中。** 四图饱和度中位数仅 **0.22 / 0.35 / 0.17 / 0.22**；p90 仅 0.46–0.55；**全画面饱和度 >0.60 的像素只占 0.5%–1.4%**。这是「低饱和」的硬证据。
- **明度：高调。** 明度中位数 **0.77–0.89**，p10 也有 0.49–0.56。暗端被压缩——**几乎没有深色**。
- **冷暖：暖中性为底，一个冷灰做对比。** 主色（砂 `#D8D0A8`、木、米、褐）全在 H=22–50° 暖区；唯一的冷色是石屋／石墙的 `#B8BFC5`（H=207°，几乎无彩 S=0.07）和雾青 `#70B0C0`。**冷暖对比是靠「暖褐 vs 冷灰」这一组几乎无彩的中性色完成的，不是靠色相撞色。**
- **近灰像素占比 18.9%–22.0%（S<0.10）**。即约五分之一到四分之一的画面是「灰的」——这是「安静」的直接来源。

【事实·来源】搜狐一篇配色分析（🔴 未署名，[sohu.com/a/219029092](https://www.sohu.com/a/219029092_252093)）称主背景色是「绿色、驼色和灰色」，绿色是「低纯度、高灰度的草绿」，并用「草绿 & 沙漠驼」概括。**这与我的实测方向一致**（砂米 `#D8D0A8` 是最常见单色，冷灰 `#B8BFC5` 第二，绿系合计约 11–13%）。但它**未给出任何 hex 值**——本文的 hex 全部来自我自己的像素读取，与该文无关。
【事实·来源】新民网称「配合青蛙主题的**浅绿色主色调**，搭配 Q 版简约的作画线条」（[wap.xinmin.cn](https://wap.xinmin.cn/content/31362147.html)）；澎湃称「游戏界面以**绿色为主色系**」（[thepaper](https://m.thepaper.cn/yidian_promDetail.jsp?contid=1968250)）。
【矛盾提示】媒体口径都说「绿色是主色」，但**实测显示覆盖率最高的单色是砂米色 `#D8D0A8`（17.8%）和冷灰 `#B8BFC5`（11.7%），不是绿色**。「绿色主色」更准确的说法是：**绿色是「记忆色／品牌色」（青蛙），砂米+冷灰才是「画面底色」**。两者并不冲突，但把绿色当成画面主色会做错。

## 2. 线条与造型

### 2.1 是否有勾线？——有，而且是最主要的造型手段

【实测】所有角色、道具、UI 都有明确勾线。**线是彩色的，不是黑色。**
**关键实测证据：全部 5 张截图中，max(RGB) < 40 的像素数量为 0（零）。** 最暗的像素约 `#382D19`（相册页）／`#4F4927`（庭院）／`#56472A`（室内），亮度约 42–66/255。**这个游戏里不存在纯黑。**

### 2.2 线色：一个统一的「暗橄榄墨色」

【实测】局部极小值（即线芯）统计，`#505848` 色桶在室内／庭院／商店三张差异极大的场景中分别占全部线芯的 **63.3% / 57.7% / 54.1%**——即**全游戏共用一支墨色**。

横切一条白标签板的线芯剖面（商店图，x=300，y=824→838）：

```
#f4bfcb (粉，平涂18px) → #e0a4ae → #af8788 → #70685d
→ #505f4c #535e4d #5c6455   ← 线芯 4px
→ #848a80 → #c9cbc6 → #ffffff (纯白，平涂46px)
```

- **线色 ≈ `#505F4C`**（H≈105° S≈0.15 V≈0.37），一支**暗橄榄绿灰**。跨场景测得的线芯值域 `#3D4335` ~ `#5C6455`。
- **重要：线色不随填充色变化。** 上面这条线的上方填充是**粉色** `#f4bfcb`，下方是**纯白** `#ffffff`，而线芯是**同一个橄榄色**。所以它**不是**日式动画常见的「色トレス」（按物体改线色），而是**一支全画面通用墨色**。

【实测】**第二支墨色：暗褐 `#58492C`**（H=40° S=0.51 V=0.35），用于**木质 UI 上的文字与图标**（如「おみせ」按钮的字与包袱图标，实测最暗 `#58492c`）。它只占线芯的约 2.5%，是 UI 专用色。
【实测】商店白标签板上的商品名文字线色仍是橄榄墨 `#505848`（众数，1510 px）。**即：文字用色在两支墨色之间按底材切换，都是暗浊色。**

### 2.3 线宽与均匀度

【实测】横切线芯宽度（商店标签板）：**核心 4px + 两侧各约 2px 抗锯齿，共约 6–8px @3x ≈ 1.3–2.7 pt**（1242px 宽 = 414pt，3x）。多线取样众数落在 6–8px @3x。
- **线宽基本均匀，无毛笔式粗细变化。** 从青蛙（5x 放大）和蜗牛（4x 放大）的截图看，轮廓线全程等宽，**线端为圆头（round cap），转角为圆角**。
- **有抗锯齿**，边缘是柔和过渡而非硬边／像素锯齿——**不是像素画**。

### 2.4 造型：圆润，但是「有机的圆」而非「几何的圆」

【实测／目测】青蛙放大 5x 后观察：轮廓完全由连续曲线构成，**无直线、无尖角、无几何化的标准圆弧**。轮廓略有手绘的不规则起伏（不是机械对称），但幅度很小。
【事实·来源】新民网称其「Q 版简约的作画线条」＋「主角青蛙那一脸淡定的表情设计」，并点出由此产生「反差萌」；光明网称其角色美术是「**儿童简笔画般**（🔴 且原文用『据称』二字，属转述）」（[gmw.cn](https://wenyi.gmw.cn/2018-01/22/content_27409126.htm)）。

### 2.5 表情设计（决定「不甜腻」的关键）

【实测／目测，5x 放大】青蛙的眼睛是**一个深橄榄色的斜杏仁形实心块**：**没有眼白、没有瞳孔、没有高光、没有星星眼、没有睫毛、没有腮红、没有嘴部夸张**。相册图里能看到嘴是一个小小的红橙色块。
【事实·来源】新民网：「一脸淡定的表情设计……透露着些许**反差萌**」（[已读全文](https://wap.xinmin.cn/content/31362147.html)）。
【推断】这是全作最重要的「去糖」手段：**可爱角色通常靠「大眼睛＋高光＋腮红」生产甜度，本作把这三样全部删掉，只留一个色块。** 观众读到的是「平静」，而不是「讨好」。

### 2.6 比例关系

【实测】主角在画面中**极小**：
- 相册照片里的青蛙 bbox = **124×109 px = 41×36 pt**，占**整屏面积 0.49%**；占照片高度的 **17.7%**。
- 室内场景（树屋）里的青蛙 bbox ≈ **64×56 px**，占屏高仅 **2.5%**。
【实测】单张截图里**覆盖率最高的单一平涂色块可达整屏 43.2%**（庭院图的砂色）。
【推断】头身比：从放大图看，青蛙是**约 1:1 的「头≈身」短胖体型**（去拟人化的蛙形，不是人形 Q 版）。但**我未能精确测量头身比**，也没有任何来源描述它——**此项标为弱证据**。
【缺口】道具／家具与青蛙的具体比例关系无来源，我也未做系统测量。

## 3. 材质与肌理

### 3.1 核心结论：**不存在全屏纸纹／颗粒／噪点覆盖层**

【实测】这是本次最干净的一个否定结论。对多处「视觉上应当平坦」的区域做 40×40 像素块统计：

| 区域 | 均值色 | 亮度标准差 | 亮度极差 | 1600 像素中的不同色数 |
|---|---|---|---|---|
| 相册天空（照片内） | `#5A91B4` | **0.99** | 4 | **8** |
| 相册天空（另一处） | `#5991B4` | **0.93** | 3 | **6** |
| 石屋墙面 | `#B8BFC5` | **0.00** | **0** | — |
| 商店淡绿墙 | `#D2E68F` | **0.00** | **0** | — |
| 相册灰褐底 | `#A19A86` | **0.00** | **0** | — |

- **SD=0.00 / 极差=0** 意味着这些区域是**逐像素完全相同的颜色**。**任何纸纹、和纸纤维、水彩纸咬色、噪点、颗粒叠加层都会破坏这一点。** 所以：**没有全屏肌理层。**
- 另一条硬证据：**单条水平方向上连续 488 px（= 163 pt）为完全同一个色值 `#DFD1AE`**。163 点长的绝对纯色——这在任何带噪点／纸纹的画面里都不可能。

### 3.2 那「肌理感」从哪来？——是**画出来的低对比笔触**，不是材质贴图

【实测】相册照片里那根树枝的「木纹」：40×40 块 SD=2.28–5.33，亮度极差 **15–30**（即对比只有 6%–12%），块内 27–93 个不同色。
【目测，4x 放大】放大后可见：树枝的「木纹」是**沿枝干方向的一组细长、低不透明度、边缘发虚（软边）的弧线笔触**，画在平坦的卡其底 `#938E71` 上。它们**不是贴图纹理**，是矢量笔触。
【实测】商店的木牌／木地板同理：木纹是画出来的深色波浪线（`#91885D` / `#B78C6A` 一类），底面是平坦的 `#E2BC69`。

**结论（实测）：本作的「肌理」= 局部绘制的、低对比（约 6–12% 亮度差）、软边的笔触细节。不覆盖全画面，只出现在木、石、叶、水等需要交代材质的对象上。**

### 3.3 唯一使用**渐变**的地方：旅行照片

【实测】相册页那张明信片内的天空：沿垂直方向 x=300，y=730→930 的连续采样是
`#548EB3 → #5991B4 → #5C94B7 → #5F95B9 → #6399BB → #679CBC`
——**单调、连续、平滑的渐变**（总幅度约 8% 亮度）。而室内／庭院／商店的**所有**大色块都是硬边平涂。
【推断】这是有意的**媒介区分**：主画面 = 平涂图形；旅行照片 = 允许渐变的「另一种画面」。**照片是被当作「另一种媒介的产物」来画的。**

### 3.4 相册底色上的「同色系暗纹」

【实测】相册页整个背景是 `#A09880`（占 42.2%），其上有一层**同色系、约 20 个亮度级的暗纹**（三叶草／叶片线稿，色约 `#847C68`，占 4.3%）。对比度约 8%。**这是全画面唯一的「图案底纹」，且只出现在相册这一页。**
【目测】商店页的淡绿墙上有极淡的横向色带；相册页右下角还有一处手写体涂鸦。

## 4. 光影与体积

### 4.1 平涂还是二分？——**平涂为主，二分极少，且二分的边界也是软的**

【实测】青蛙本体 `#7EAA51` 在垂直方向 **35 个连续像素内完全恒定**，然后过渡到嘴部的红橙色——**没有任何中间调**。石墙、淡绿墙、模态面板蓝 `#9CD5EE`（1100+ 像素恒定）同理。
【实测】商店一块粉色风吕敷剖面：`#F4BFCB`（平涂 18px）→ 约 6px 过渡 → `#F2A0AE`（平涂 14px+）。这是**两档平涂色 + 抗锯齿过渡**，不是连续渐变。
**结论：全画面是「平涂（平涂 + 少量 2 档色阶）」，没有连续渐变（照片除外）。**

### 4.2 有投影吗？

【实测】**角色和道具没有投影。** 蜗牛（庭院）底部扫描：蜗牛体 → 橄榄墨线 → 直接进入砂地 `#EDD29B`，**中间没有暗带**。青蛙、树桩、邮筒同理。
【实测】**UI 层有软投影。** 商店页白色标签板的下缘：`#F8F8F8` →（软渐变 6px）→ `#8F9289` →（软渐变 8px）→ `#FDFDFD`；右侧边缘同样有一条软渐变带。这是**软边（模糊）投影**。
**结论：美术层无投影（纯靠勾线分离物体）；UI 层用软边投影把面板从背景上「抬起来」。这是一个刻意的分层。**

### 4.3 有高光吗？

【实测／目测】角色上**没有高光、没有边缘光、没有渐变高光**。UI 图标（如「おみせ」的蓝色包袱）内有**一小块纯白平涂**作为高光——是**平涂白色色块**，不是渐变高光。
【实测】商店的软木／木质表面有一条比底色略亮的暖色带（例如按钮木面从 `#E2BC69` 渐亮到 `#ECC673`）——幅度约 3% 亮度，**是极轻的「受光面」提示，不是高光**。

### 4.4 夜景（本次的明确缺口）

【事实·来源】夜间照明是玩法的一部分：室内有蜡烛／灯道具，夜晚蜡烛会亮（[tantannews](https://tantannews.com/tech/openAE4d7A)、3DM／9game 多篇攻略标题级）。
【缺口】**本次完全未能取到夜间截图**，因此「夜晚是否全屏压暖／压暗」「是否有光晕」**无法给出一手答案**。任何关于夜间色调的描述在此都只能是猜测——**不要写**。
【推断】（低置信）结合「无渐变、无双色阶」的整体手法，夜景更可能是**整屏色调替换／压暗 + 局部平涂暖色块**，而非写实光照。**此为推断，无证据。**

## 5. 构图与留白

### 5.1 信息密度：极低，且有实测数字

【实测】非亮像素（亮度<120，即线＋暗部）覆盖率：

| 截图 | 内容 | 线／暗部覆盖率 |
|---|---|---|
| 相册 | 基本空白的相册页 | **6.35%** |
| 商店 | 商品列表页 | **9.48%** |
| 室内（树屋） | 细节最多的场景之一 | **12.78%** |
| 庭院 | 草地／叶丛，最密 | **19.20%** |

**即：连最复杂的场景，也只有不到五分之一的像素是「线或暗部」。** 其余 80%+ 是亮部平涂。
【事实·来源】澎湃：「游戏中能为玩家提供交互的元素极少，只有收割植物、查看邮件、准备便当等，**使得整个游戏更像一个只有两页的漫画故事**」；「它并没有给玩家提供华丽的色彩、炫目的电脑特效」；「用静态的人工符号构建了游戏中的『枯山水』景观」（[已读全文](https://m.thepaper.cn/yidian_promDetail.jsp?contid=1968250)）。

### 5.2 主体占比：主角是「点缀级」的

【实测】青蛙占整屏面积 **0.49%**（相册）／屏高 **2.5%**（室内）。**主人物的视觉权重极低**——这在一款以该角色命名的游戏里非常反直觉，也是「安静」的结构性原因。
【实测】反过来说，**「空」的权重极高**：单一平涂色块可占整屏 **43.2%**；相册页底色 `#A09880` 占 42.2%；背包弹窗的淡蓝 `#9CD5EE` 占 33.4%。

### 5.3 留白比例与「呼吸感」的实现方式

【实测／推断】
- **留白是「同色系的大面积平涂」，不是白色。** 庭院图的砂色占 43%、相册底占 42%、弹窗蓝占 33%——这些是"空"，但它们**有颜色、有温度**（暖砂色、暖灰褐、冷天蓝），不是刺眼的纯白。**这是「安静」而不「冷清」的关键。**
- 【实测】**弹窗没有背景压暗（scrim）。** 背包弹窗覆盖在室内场景上时，四周的房间依然是全亮度（树桩、地板、火把清晰可见，未被压暗）。**大多数手游会加一层黑色半透明遮罩——本作不加。** 这直接避免了画面出现大面积暗部，维持了高调明度。
- 【推断】视线引导靠**勾线的密度差**而非色彩对比：蛙／道具用高密度勾线「聚焦」，背景用大面积无勾线的平涂「退后」。全画面没有景深模糊、没有暗角。

### 5.4 构图手法

【目测】单点透视 + 略微俯视的固定机位；场景填满画面但不做「框景」；UI 元素（木牌按钮）被画成**场景内的道具**（钉在木板上），而不是浮在画面上的系统 UI——**UI 与美术同材质、同墨色、同风格**，这是很强的统一性设计。
【事实·来源】相册照片取景自日本真实景点（名古屋城、有馬温泉、草津温泉、屋久島縄文杉等），玩家侧有系统整理（[ついラン](https://tsuiran.jp/pickup/20190130/21658)，🔴 粉丝整理）。开发者自述：「这款游戏本身是以日本国内作为开发对象，所以当初收集了很多日本国民一定知道的著名景点」（新京报访谈，[已读全文](http://news.sina.com.cn/s/wh/2018-01-28/doc-ifyqyesy3039280.shtml)）。

## 6. 字体

### 6.1 实测结论：游戏内是**两套文字系统**，不是一套字体

【实测／目测，3–5x 放大截图后判读】

**系统 A：标题／装饰字 —— 手绘字（不是字体）**
- 样本：「アルバム」（相册页标题）、「SHOP」、「かばん」、「したく」、「おみせ」、「にわさき」等木牌文字。
- 特征：**笔画粗细明显不均**（如「SHOP」的 S 上粗下细、H 的竖画两端圆钝）；**几何故意不规整**（SHOP 的 O 是蛋形、P 与 H 相叠）；笔画**末端带圆头和轻微墨积**；整体有强烈的手写笔触感。
- **判据：机械渲染的字体不可能产生这种逐字不规则的笔画宽度和轴倾。判定为手绘字（或极强的手写风格化处理）。**
- 标题字带**「外描边 + 浅色内芯」**的双层结构（如「アルバム」= 深褐描边 + 米白内芯），即「袋文字」。描边色接近 `#5A4A30`。

**系统 B：正文／标签字 —— 手写风圆体（是字体，非手绘）**
- 样本：商店商品名「えびぶるのスコーン」「はこべのサンドイッチ」、背包标签「おべんとう」「おまもり」「どうぐ」。
- 特征：平假名转折圆润、笔画末端圆钝、**字形有轻微手写的不规整感**，但**同尺寸字号的笔画是机械一致的**——说明是**渲染的字体**。
- 墨色实测 `#505848`（橄榄墨），最暗 `#414A39`。
- 【目测】白标签板上的商品名疑似带一层**极淡的深色描边／投影**（让字在白底上更实）。
- **类别判定：【目测·中置信】手写风格的圆ゴシック（手書き風丸ゴシック）**。
- 【缺口】**具体字体名查不到。** 我做了中／日／英多组检索（「旅かえる フォント」「フォント特定」「旅行青蛙 字体」等），**日文 font-identification 社区没有该游戏的字体讨论帖**；游戏拆包资源清单未查（子代理无 WebFetch，且检索配额耗尽）。**不猜字体名。**

### 6.2 一个干扰项（必须澄清）

【事实·来源】中文圈存在一款**商用字体「方正手迹-旅行青蛙体」**（方正官方目录 [foundertype.com/FontInfo/4771](https://www.foundertype.com/index.php/FontInfo/index/id/4771/)，授权商品 ID `FZSJ-LXQWTJW`，元数据「Regular Version 1.00」，多站标注「商用须授权」，如 [zzfont](https://www.zzfont.com/font/1105993/)）。
【缺口】**该字体与游戏的关系完全无法证实。** 所有已查页面均**不能说明**它是官方合作字体、还是仅借用 IP 名字的商业字体，也**不能说明**官方中文版《旅行青蛙：中国之旅》（阿里游戏，2018-05 淘宝内测，[游民星空](https://shouyou.gamersky.com/news/201805/1043692.shtml)）用的是不是它。**不要把它写成「游戏用的字体」。**

### 6.3 其他

【缺口】竖排（縦書き）文字：**零来源，未确认**。信纸／邮票／信封的排版设计分析：**未找到任何字体学或设计学分析**。
【推断】信件正文是可变内容（玩家收到不同的信），逐句手绘不现实，因此信纸文字**大概率是渲染字体**——但**无来源，属推断**。

### 7.2 与「一般可爱卡通风格」的具体区别（本品最核心的一问）

以下每一条都尽量落到**实测数字**上，而不是形容词：

**① 眼睛：删掉了可爱的三件套。**
三丽鸥／扁平淡色插画／粗描边儿童插画的主角，几乎都靠**大眼＋高光（星星眼）＋腮红**生产甜度。本作青蛙的眼睛是**一个深橄榄色实心色块**——无眼白、无瞳孔、无高光、无腮红、无嘴部夸张【实测，5x 放大】。**可爱度不是靠「加表情」而是靠「造型比例」得出的，因此不「腻」。**

**② 饱和度：把「快乐色」压掉了。**
【实测】全画面饱和度中位数 0.17–0.35，**饱和度 >0.60 的像素仅 0.5%–1.4%**；近灰像素（S<0.10）占 **18.9%–22.0%**。这是「安静」最直接的物理来源——**画面里几乎不存在「兴奋色」**。

**③ 明度：高调、无暗部。**
【实测】明度中位数 0.77–0.89，p10 仍有 0.49–0.56。**画面没有深色区**（并且没有弹窗压暗遮罩）。低对比＋高明度 = 视觉不刺激。

**④ 轮廓线：是彩色的、暗浊的、中等粗细的。**
【实测】线色 `#505F4C`（暗橄榄），**不是黑色**，全场零纯黑像素。对比「粗描边儿童插画」（纯黑粗线，视觉冲击强、偏吵闹）和「扁平淡色插画」（常完全无描边），本作是**第三条路：有描边、但描边是暗浊的彩色、粗细克制（约 1.3–2.7pt）**。

**⑤ 主角的视觉权重被刻意压低。**
【实测】青蛙占屏 **0.49%**。可爱风游戏通常**放大**主角以强化萌感；本作反其道而行——**主角是画面里的一个小存在**，大量面积让给「空」。这是「克制」在构图层的体现。

**⑥ 平涂但绝不平淡：靠「绘制的低对比肌理」补信息量。**
【实测】无全屏纹理／噪点／纸纹（多处 SD=0.00）；肌理是**局部软边笔触，对比仅 6–12%**。这与水彩绘本（大面积晕染、高肌理随机性）和像素风都不同。

**⑦ 拒绝超现实：不加幻想特效。**
【事实·来源】设计师上村真裕子原话：「**因为要体现的是一种以现实为舞台的世界观，所以不会过多添加超现实的幻想要素。**」（新京报访谈，[已读全文](http://news.sina.com.cn/s/wh/2018-01-28/doc-ifyqyesy3039280.shtml)）。**没有魔法光效、没有粒子、没有闪光星星。** 这是「不热闹」的直接原因。

**⑧ 设计意图层面：明确「不竞争」。**
【事实·来源】同一访谈：「我们希望玩家之间**不要竞争、抢夺**，大家能够按照个人的步调悠闲地游玩享受游戏，是我们开发《旅行青蛙》的本意。」；「青蛙会随性行动，玩家会对青蛙的去向感到不安，也会对青蛙旅行回来后感到开心，这些不同心情的累积可能会让玩家产生一种**庇护心**吧。」
【事实·来源】制作人高崎豊：「我们将这些细节**掩盖起来**，希望玩家一边玩一边探索，并获得探索新事物带来的喜悦。」（[GameRes 转载界面，已读全文](https://www.gameres.com/806572.html)）
【事实·来源】澎湃对同一气质的描述：「并没有给玩家提供华丽的色彩、炫目的电脑特效……**而是用静态的人工符号构建了游戏中的『枯山水』景观，用慢节奏的机制来达成互动体验**」；「处处体现出**古朴的意境**」。

**⑨ 与三丽鸥的直接对比：查不到任何来源。**
【缺口 + 诚实声明】我专门检索了「三丽鸥／Hello Kitty 对比」「粗描边儿童插画」「像素风」「flat pastel」四个方向，**全部零相关结果**。**「与三丽鸥的区别」是本报告的原创分析，不是任何来源的观点**——上面①–⑧是我基于实测数据的判断，请按「推断」使用，不要写成「有分析认为」。

### 7.3 来源间的冲突（不和稀泥）

1. **「浮世绘」vs「箱庭／禅」——美术祖先之争。** 雅昌艺术网《「养蛙」好比葛优躺和丧文化 **浮世绘才是它亲妈**》（[artron](https://news.artron.net/20180129/n985816.html)，🟡 未读正文）主张浮世绘画风谱系；澎湃主张箱庭＋枯山水＋侘寂。**两者不可调和。** 就我的实测证据看，本作是**平涂＋彩色勾线＋无渐变**，与浮世绘（木版多色摺、有晕染、有渐变「ぼかし」）**技法上不吻合**；「箱庭／枯山水」是**空间与文化框架**的描述，不是笔法描述——**两者其实不在同一个层面上争论**。我倾向：**箱庭是可信的空间美学定位，浮世绘是媒体修辞。**
2. **华语舆论「治愈／佛系」vs 英文媒体「孤独」。** Polygon 评测标题即结论：*doesn't recapture the magic — Travel Frog feels pretty lonely*（[polygon.com](https://www.polygon.com/2018/1/8/16863926/tabi-kaeru-travel-frog-neko-atsume-hit-point/)，🟡 未读正文）。**同一个设计特征，被读成「治愈」也被读成「孤独」。** 这说明「克制」是双刃剑，不是无争议的优点——如果你的游戏要借鉴它，**必须接受一部分玩家会读成「冷清、没事干」**。
3. **澎湃自家两个立场。** 澎湃同期还发了一篇《孤独的「旅行青蛙」，其实并不是你想要的样子》（[thepaper 1966021](https://www.thepaper.cn/newsDetail_forward_1966021)），与「禅派治愈」相反。
4. **团队人数四种口径冲突**（见 §9）。**不要引用任何单一数字。**

### 7.4 一句话的谱系判断

【推断】本作不属于「水彩绘本」谱系（**注意：我未能找到任何来源把它归入绘本／水彩谱系；中文圈把「水彩感」用在它身上是受众感知，不是创作者谱系**）。它更准确的定位是：**日式「箱庭」空间美学 + 商业扁平插画（flat vector illustration）的工艺 + 极简主义的信息密度 + 侘寂的审美取向**。**它的「安静」不主要来自画法（画法是商业扁平插画），而来自「画法之上的一整套减法决策」：删表情、删饱和、删暗部、删特效、删主体面积、删交互、删竞争。**

## 8. 可复现性评估

### 8.1 可以安全复用（技法层，属于公共技法，不构成抄袭）

| 特征 | 实测参数（可直接照做） | 复用风险 |
|---|---|---|
| **单色墨线系统** | 全场用**一支**暗橄榄墨 ≈ `#505F4C`（值域 `#3D4335`–`#5C6455`），**永不使用纯黑** | 极低。这是通用技法。**但请换掉具体色值**（见 8.2） |
| **色トレス 的反面**：线色不随填充变化 | 粉底/白底共用同一墨色 | 无风险 |
| **线宽与线端** | 约 1.3–2.7 pt（3x 下 4–8px），**等宽**，圆头线端，圆角转角，抗锯齿 | 无风险 |
| **平涂 + 硬边** | 大面积色块逐像素恒定（SD=0.00）；**单色最长连续 163 pt** | 无风险。**关键是「敢平」**——很多团队忍不住加噪点/渐变 |
| **低对比局部肌理** | 木纹/石纹用**软边、低不透明度**笔触，亮度差仅 **6–12%** | 无风险 |
| **无全屏纹理层** | 不加纸纹、不加噪点、不加暗角 | 无风险 |
| **两色阶二分** | 需要体积时只用 2 档平涂 + 抗锯齿过渡，**不用连续渐变** | 无风险 |
| **美术层无投影** | 靠勾线分离物体；**只给 UI 面板加软边投影** | 无风险，分层策略值得学 |
| **弹窗不压暗背景** | 无 scrim，保持全画面高调 | 低风险，是有效的手法 |
| **高明度 + 低饱和的数值区间** | 明度中位数 **0.77–0.89**；饱和度中位数 **0.17–0.35**；高饱和（>0.60）像素 **<1.5%**；近灰（<0.10）像素 **19–22%** | 无风险。**这组数字是本次最可直接搬运的成果** |
| **删掉可爱的三件套** | 眼睛=实心色块；无高光、无腮红、无星星眼、无嘴部夸张 | 无风险，且是最有效的「去糖」手段 |
| **主角小、留白大** | 主角占屏 **<1%**；单色平涂块占屏可达 **40%+**；线覆盖 **6–19%** | 无风险 |
| **UI 即道具** | 按钮画成场景内材质（木牌），与美术同墨色同风格 | 无风险 |
| **「照片」用另一种媒介** | 主画面严格平涂，照片允许渐变——用媒介差异讲故事 | 无风险，很值得学 |
| **手绘标题字 + 圆体正文的两套文字系统** | 标题手绘（袋文字：深描边+浅内芯），正文用渲染的手写风圆体 | 无风险 |

### 8.2 强绑定于原作，照搬会变成抄袭（IP／识别层）

| 特征 | 为什么不能抄 |
|---|---|
| **具体色值组合本身**：砂米 `#D8D0A8` + 冷灰 `#B8BFC5` + 蛙绿 `#7EAA51` + 米 `#E0D8B8` + 墨 `#505F4C` | 这套**具体的、低频的、被玩家反复观看的**组合已经是该 IP 的视觉签名。**换一套同结构、不同色值的方案**（保留「低饱和高明度 + 一支暗浊彩色墨线 + 一个暖中性底色 + 一个冷中性对比色」的关系），才是借鉴。 |
| **「一只小动物 + 一个箱子 + 大量留白」的整体构图公式** | 这是被媒体反复定义、被消费者直接指认「这是旅行青蛙那种」的组合。照搬=抄袭。 |
| **木牌式 UI 的形态**（木质圆角牌 + 手绘字 + 深描边） | 该形态是该作最具辨识度的 UI 语汇。 |
| **青蛙 + 三叶草 + 木屋 + 明信片的具体母题** | 直接 IP 元素。 |
| **青蛙「一脸淡定 + 实心色块眼」的具体表情造型** | 该角色设计已被大量玩家与媒体指认为「反差萌」并成为该作的符号。 |
| **相册／明信片的整套界面结构**（牛皮纸卡 + 白相框 + 手写涂鸦底纹） | 该页面的具体版式辨识度很高。 |
| **「旅行照片取景自真实地标」的机制＋美术做法** | 机制可借鉴，但**照抄「真实地标写生集」的呈现方式**会显得是在复制产品概念。 |

### 8.3 我的建议（如果要在新项目里用这套风格）

**安全的做法是抄「约束」而不是抄「结果」**：
1. 定一组**自己的**约束：明度中位 ≥0.75、饱和中位 ≤0.35、高饱和像素 ≤2%、近灰像素 ≥15%、线覆盖 ≤20%、主角占屏 ≤3%、单色块最大连续 ≥100pt。
2. 定**一支自己的墨色**（暗浊、非黑、非棕，例如偏紫的暗灰或偏青的暗灰），全项目共用，线色不随填充变化。
3. 定**自己的**「去糖」清单：删高光、删腮红、删粒子、删暗角、弹窗不压暗。
4. **保留**：平涂硬边、低对比局部笔触、UI 即道具、照片用另一种媒介。
5. **换掉**：母题（不一定是动物、不一定是箱子）、具体色相、UI 形态（不用木牌）、文字风格（不用同一类手写圆体）。

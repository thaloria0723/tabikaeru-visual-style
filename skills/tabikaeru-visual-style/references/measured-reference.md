### 色彩性格（实测）

- **饱和度低到中**：四图饱和度中位仅 **0.22 / 0.35 / 0.17 / 0.22**；p90 仅 0.46–0.55；全画面 **S>0.60 的像素只占 0.5%–1.4%**
- **明度高调**：明度中位 **0.77–0.89**，p10 也有 0.49–0.56。**暗端被压缩**
- **冷暖对比靠近中性色**：主色全在 H22–50° 暖区；唯一冷色是 `#B8BFC5`（H207，S0.07 几乎无彩）和雾青。**对比是「暖褐 vs 冷灰」完成的，不是色相撞色**
- **近灰像素（S<0.10）占 18.9%–22.0%**——约 1/5 画面是「灰的」，这是「安静」的直接来源

### ⚠️ 与媒体口径的矛盾

媒体都说「绿色是主色」，但实测覆盖率最高的是砂米 `#D8D0A8`（17.8%）和冷灰 `#B8BFC5`（11.7%）。

**准确说法：绿色是「记忆色／品牌色」（青蛙），砂米＋冷灰才是「画面底色」。把绿色当画面主色会做错。**

## 2. 线条

【实测】**全场零纯黑**——5 张截图中 `max(RGB) < 40` 的像素数量为 **0**。最暗像素约 `#382D19`（相册）／`#4F4927`（庭院）／`#56472A`（室内），亮度 42–66/255。

### 一支墨色，全项目共用

【实测】线芯色桶统计，`#505848` 在室内／庭院／商店三张差异极大的场景中分别占全部线芯的 **63.3% / 57.7% / 54.1%**。

```
剖面（商店图 x=300, y=824→838）：
#f4bfcb (粉，平涂18px) → #e0a4ae → #af8788 → #70685d
→ #505f4c #535e4d #5c6455   ← 线芯 4px
→ #848a80 → #c9cbc6 → #ffffff (纯白，平涂46px)
```

- **线色 ≈ `#505F4C`**（H105 S0.15 V0.37），暗橄榄绿灰。跨场景值域 `#3D4335`–`#5C6455`
- **线色不随填充色变化**：上方填充是粉色、下方是纯白，**线芯是同一个橄榄色**。不是日式动画的「色トレス」，是**一支全画面通用墨色**

【实测】**第二支墨色 `#58492C`**（H40 S0.51 V0.35），暗褐，用于**木质 UI 上的文字与图标**，约占线芯 2.5%。即：文字用色按底材在两支墨色间切换，都是暗浊色。

### 线宽

【实测】线芯 **4px + 两侧各约 2px 抗锯齿 = 6–8px @3x ≈ 1.3–2.7 pt**
- **线宽均匀，无毛笔式粗细变化**；线端圆头（round cap），转角圆角
- **有抗锯齿**，非像素画

### 造型

- 【目测】轮廓由连续曲线构成，**无直线、无尖角、无几何化标准圆弧**；有轻微手绘不规则起伏，幅度很小
- 【目测·弱证据】约 **1:1 头≈身的短胖体型**（去拟人化的蛙形，不是人形 Q 版）。**头身比未精确测量，无来源**

## 3. 材质与肌理

### 【实测】不存在全屏纸纹／颗粒／噪点覆盖层

这是最干净的否定结论：

| 区域 | 均值色 | 亮度 SD | 亮度极差 | 1600px 中不同色数 |
|---|---|---|---|---|
| 相册天空（照片内） | `#5A91B4` | 0.99 | 4 | 8 |
| 石屋墙面 | `#B8BFC5` | **0.00** | **0** | — |
| 商店淡绿墙 | `#D2E68F` | **0.00** | **0** | — |
| 相册灰褐底 | `#A19A86` | **0.00** | **0** | — |

**SD=0.00 / 极差=0 = 逐像素完全相同。** 另一条硬证据：**单条水平方向连续 488px（=163pt）为完全同一个色值 `#DFD1AE`**。

### 【实测】肌理是「画出来的低对比笔触」

树枝「木纹」：40×40 块 SD=2.28–5.33，亮度极差 **15–30（对比仅 6%–12%）**，块内 27–93 个不同色。

放大可见：木纹是**沿枝干方向的细长、低不透明度、边缘发虚（软边）的弧线笔触**，画在平坦卡其底 `#938E71` 上。**不是贴图纹理，是矢量笔触。**

> **结论：肌理 = 局部绘制的、低对比（6–12%）、软边的笔触细节。不覆盖全画面，只出现在木、石、叶、水等需要交代材质的对象上。**

### 【实测】唯一使用渐变的地方：旅行照片

相册明信片内的天空，垂直方向连续采样：
`#548EB3 → #5991B4 → #5C94B7 → #5F95B9 → #6399BB → #679CBC`
——**单调、连续、平滑的渐变**（总幅度约 8% 亮度）。而室内／庭院／商店的**所有**大色块都是硬边平涂。

【推断】这是有意的**媒介区分**：主画面 = 平涂图形；旅行照片 = 允许渐变的「另一种画面」。**照片被当作「另一种媒介的产物」来画。** 这是本作很值得学的一招。

### 【实测】相册底纹

相册页背景 `#A09880`（42.2%），其上有一层**同色系、约 20 个亮度级的暗纹**（三叶草／叶片线稿，约 `#847C68`，占 4.3%），对比度约 8%。

**这是全画面唯一的「图案底纹」，且只出现在相册这一页。**

## 4. 光影与体积

### 【实测】纯平涂

青蛙本体 `#7EAA51` 在垂直方向 **35 个连续像素内完全恒定**，然后直接过渡到嘴部红橙——**没有任何中间调**。模态面板蓝 `#9CD5EE` 在 1100+ 像素内恒定。

需要体积时用**两档平涂色 + 抗锯齿过渡**：如粉色风吕敷 `#F4BFCB`（平涂 18px）→ 约 6px 过渡 → `#F2A0AE`（平涂 14px+）。**不是连续渐变。**

### 【实测】投影：美术层没有，UI 层有

- **角色和道具无投影**。蜗牛底部扫描：蜗牛体 → 橄榄墨线 → **直接进入砂地 `#EDD29B`，中间没有暗带**
- **UI 层有软边投影**。白标签板下缘：`#F8F8F8` →（软渐变 6px）→ `#8F9289` →（软渐变 8px）→ `#FDFDFD`

> **这是一个刻意的分层：美术靠勾线分离物体，UI 靠软投影从背景上「抬起来」。**

### 【实测】无高光

角色上**没有高光、没有边缘光**。UI 图标（蓝色包袱）内有**一小块纯白平涂**作为高光——是平涂色块，不是渐变高光。

### 【缺口】夜景

**完全未取到夜间截图。** 「夜晚是否全屏压暖／压暗」「是否有光晕」**无法给出一手答案**。任何关于夜间色调的描述都只能是猜测——**不要写**。

## 5. 构图与留白

### 【实测】线＋暗部覆盖率

| 内容 | 覆盖率 |
|---|---|
| 相册（基本空白页） | **6.35%** |
| 商店（商品列表） | **9.48%** |
| 室内树屋（细节最多场景之一） | **12.78%** |
| 庭院（草地叶丛，最密） | **19.20%** |

**连最复杂的场景，也只有不到 1/5 的像素是「线或暗部」。**

### 【实测】主体占比

- 青蛙 bbox 124×109px，占**整屏面积 0.49%**；占照片高度 17.7%
- 室内树屋里的青蛙 bbox ≈64×56px，占屏高仅 **2.5%**
- 反过来说，「空」的权重极高：**单一平涂色块最高占屏 43.2%**

### 【实测／推断】留白与呼吸感

- **留白是「同色系的大面积平涂」，不是白色**：庭院砂色 43%、相册底 42%、弹窗蓝 33%。这些是「空」，但**有颜色、有温度**——这是「安静」而不「冷清」的关键
- **弹窗没有背景压暗（scrim）**：背包弹窗覆盖在室内场景上时，四周房间依然全亮度（树桩、地板、火把清晰可见）。**大多数手游会加黑色半透明遮罩——本作不加。** 这直接避免了大面积暗部，维持高调明度
- 视线引导靠**勾线密度差**而非色彩对比：主体用高密度勾线「聚焦」，背景用大面积无勾线平涂「退后」。**没有景深模糊、没有暗角**

### 【目测】构图手法

单点透视 + 略微俯视的固定机位；场景填满画面但不做框景；**UI 元素被画成场景内的道具**（木牌钉在木板上），不是浮在画面上的系统 UI——UI 与美术**同材质、同墨色、同风格**。

## 6. 字体

【实测／目测】**两套文字系统，不是一套字体。**

**系统 A：标题／装饰字 —— 手绘字（不是字体）**
- 特征：**笔画粗细明显不均**；**几何故意不规整**（如「SHOP」的 O 是蛋形、P 与 H 相叠）；笔画末端圆头和轻微墨积
- 判据：机械渲染的字体不可能产生这种逐字不规则的笔画宽度和轴倾 → **判定为手绘字**
- 带**「外描边 + 浅色内芯」双层结构**（袋文字），描边色近 `#5A4A30`

**系统 B：正文／标签字 —— 手写风圆体（是字体，非手绘）**
- 特征：转折圆润、笔画末端圆钝、有轻微手写不规整感，但**同字号笔画机械一致**
- 墨色 `#505848`，最暗 `#414A39`
- 【目测·中置信】手写风格的圆ゴシック（手書き風丸ゴシック）

### 【缺口】

**具体字体名查不到。** 中／日／英多组检索均未找到字体识别讨论帖。**不猜字体名。**

### ⚠️ 一个必须澄清的干扰项

存在商用字体**「方正手迹-旅行青蛙体」**。**该字体与游戏的关系完全无法证实**——不能说明它是官方合作字体还是仅借用 IP 名字。**不要把它写成「游戏用的字体」。**

## 7. 风格谱系

### 有来源背书的定位

| 定位 | 来源 | 可信度 |
|---|---|---|
| **箱庭（はこにわ）+ 禅派治愈** | 澎湃长文；该文已被西交利物浦大学学术门户以英文题名登记 | 🟢 |
| **侘寂（wabi-sabi）** | 澎湃文中明确写「充满禅意的侘寂之美」，定义「侘び（恬静、闲寂）+ 寂（孤寂、苍老或古雅）」 | 🟢 |
| **枯山水** | 澎湃：「用砂砾代替真实的水……包括精心布置的石头、苔藓、灌木及常绿树木等静态元素」 | 🟢 |
| **森系** | 澎湃：「森系『箱庭』空间」 | 🟢 |
| 佛系 | 中文互联网最主流标签 | 🟡 |

### 【事实·来源】开发者原话（设计意图）

> 「因为要体现的是一种以现实为舞台的世界观，所以**不会过多添加超现实的幻想要素**。」
> 「我们希望玩家之间**不要竞争、抢夺**，大家能够按照个人的步调悠闲地游玩享受游戏，是我们开发《旅行青蛙》的本意。」
> ——上村真裕子（游戏策划／项目负责人）

> 「我们将这些细节**掩盖起来**，希望玩家一边玩一边探索。」
> ——高崎豊（制作人）

⚠️ 中文媒体常把上村真裕子称为「设计师」，但**没有任何来源说她是插画师**，请勿混淆。

### 谱系判断

【推断】本作不属于「水彩绘本」谱系（**未找到任何来源把它归入绘本／水彩谱系；中文圈说的「水彩感」是受众感知，不是创作者谱系**）。

更准确的定位：**日式「箱庭」空间美学 + 商业扁平插画的工艺 + 极简主义信息密度 + 侘寂的审美取向。**

**它的「安静」不主要来自画法，而来自画法之上的一整套减法决策。**

### ⚠️ 冲突不下判断

**Polygon 评测标题即结论：*Travel Frog feels pretty lonely*。** 同一个「克制」被读成治愈也被读成孤独。

**这说明「克制」是双刃剑。** 借鉴它必须接受：一部分玩家会读成「冷清、没事干」。

## 8. 可复用 vs 会构成抄袭

### 8.1 可安全复用（通用技法）

| 特征 | 实测参数 |
|---|---|
| 单色墨线系统 | 一支暗浊墨色，**永不用纯黑**（**换掉具体色值**） |
| 线色不随填充变化 | 粉底／白底共用同一墨色 |
| 线宽与线端 | 1.3–2.7pt @3x，等宽，圆头，圆角，抗锯齿 |
| 平涂 + 硬边 | 大面积色块逐像素恒定；单色最长连续 163pt。**关键是「敢平」** |
| 低对比局部肌理 | 软边、低不透明度笔触，亮度差 **6–12%** |
| 无全屏纹理层 | 不加纸纹、不加噪点、不加暗角 |
| 两色阶二分 | 只用 2 档平涂 + 抗锯齿过渡 |
| 美术层无投影 | 靠勾线分离物体；**只给 UI 面板加软边投影** |
| 弹窗不压暗背景 | 无 scrim，保持全画面高调 |
| **高明度 + 低饱和的数值区间** | 明度中位 0.77–0.89；饱和中位 0.17–0.35；高饱和 <1.5%；近灰 19–22%。**这组数字是最可直接搬运的成果** |
| 删掉可爱的三件套 | 眼睛=实心色块；无高光、无腮红、无星星眼 |
| 主角小、留白大 | 主角 <1%；单色块可达 40%+；线覆盖 6–19% |
| UI 即道具 | 按钮画成场景内材质，与美术同墨色同风格 |
| 「照片」用另一种媒介 | 主画面严格平涂，照片允许渐变 |
| 两套文字系统 | 标题手绘（袋文字），正文手写风圆体 |

### 8.2 强绑定原作，照搬会构成抄袭

| 特征 | 为什么不能抄 |
|---|---|
| **具体色值组合**：砂米 + 冷灰 + 蛙绿 + 米 + 墨 | 这套具体的、低频的、被玩家长时间反复观看的组合已是该 IP 的**视觉签名** |
| 「一只小动物 + 一个箱子 + 大量留白」的构图公式 | 被媒体反复定义、被消费者直接指认「这是旅行青蛙那种」 |
| 木牌式 UI 的具体形态 | 该作最具辨识度的 UI 语汇 |
| 青蛙 + 三叶草 + 木屋 + 明信片的具体母题 | 直接 IP 元素 |
| 青蛙「一脸淡定 + 实心色块眼」的具体表情造型 | 已被大量玩家与媒体指认为该作符号 |
| 相册／明信片的整套界面结构 | 具体版式辨识度很高 |
| 「旅行照片取景自真实地标」的呈现方式 | 机制可借鉴，照抄呈现方式会显得在复制产品概念 |

### 8.3 建议做法

**抄「约束」而不是抄「结果」：**

1. 定一组**自己的**约束：明度中位 ≥0.75、饱和中位 ≤0.35、高饱和像素 ≤2%、近灰像素 ≥15%、线覆盖 ≤20%、主角占屏 ≤3%、单色块最大连续 ≥100pt
2. 定**一支自己的墨色**（暗浊、非黑、非棕，例如偏紫或偏青的暗灰），全项目共用
3. 定**自己的**去糖清单
4. **保留**：平涂硬边、低对比局部笔触、UI 即道具、照片用另一种媒介
5. **换掉**：母题、具体色相、UI 形态、文字风格
